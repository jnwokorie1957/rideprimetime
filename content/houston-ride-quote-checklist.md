# What to Have Ready Before Requesting a Wheelchair or Ambulatory Ride in Houston

Before calling about a ride, it helps to gather a few details in one place. The goal is to explain the trip clearly and find out what still needs to be confirmed.

RidePrimetime provides private-pay wheelchair and ambulatory non-emergency transportation across Houston. Route suitability, timing and capacity are confirmed individually. Its [trip-planning information](https://www.rideprimetime.net/) asks riders to discuss pickup and destination details, arrival time, mobility needs and return arrangements before booking.

## Start with the destination and required arrival time

Write down the destination's full address, building name and the entrance you have been asked to use. A campus name alone may leave the meeting point unclear. If you do not know the entrance, ask the destination before treating it as settled.

Keep the appointment time separate from the time you have been asked to arrive. Then ask the transportation provider to discuss pickup arrangements. Avoid turning your own estimate of the drive into an assumed pickup commitment.

For a Texas Medical Center visit, check the campus's [Updates and Alerts](https://www.tmc.edu/operations/tmc-campus/updates-and-alerts/) page when planning. It publishes road, parking and campus notices and warns that details can change. Confirm relevant access instructions with the destination; an older screenshot may not reflect the current arrangement.

## Explain how the rider will travel

Tell the provider whether you are asking about travel in a wheelchair or in a passenger seat. Mention mobility aids and the boarding assistance you want to discuss. If you are unsure which service is suitable, say so instead of selecting an option by guesswork.

A useful question is: “What information do you need to check whether this trip and boarding arrangement can be accommodated?” Let the provider explain what it can offer.

If a companion will travel, include that in the inquiry. Ask whether there is space and whether it changes the quote. Do not assume that a companion, equipment or a particular kind of assistance is included without discussing it.

## Give the return journey its own questions

Knowing when an appointment begins does not necessarily tell you when the rider will be ready to leave. If the return time is uncertain, explain that when asking about the outward trip.

Ask:

- How should an uncertain return time be handled?
- Who should contact whom when the rider is ready?
- Where would the return pickup take place?
- What happens if the timing changes?
- What return arrangements, if any, are included in the quoted price?

These questions do not imply that a vehicle waits at the destination or that an immediate return ride is available. Those details need an answer from the provider.

## Keep a short planning note

A **hypothetical preparation note**, using no real rider details, could look like this:

- Destination address and building: ready to discuss.
- Entrance or meeting point: still to confirm with the destination.
- Required arrival time: known.
- Preferred travel arrangement and mobility aids: ready to discuss.
- Companion: ask about space and pricing.
- Return time: uncertain; ask how it can be arranged.
- Reservation status: inquiry only.

The unfinished items are useful. They show what needs a conversation instead of hiding uncertainty behind a completed-looking form or message.

## Ask what the quote includes

Before accepting arrangements, ask which parts of the trip the price covers. Clarify the outward journey, return journey, any agreed waiting arrangements and how changes or cancellations would be handled.

Write down the answer rather than relying on an assumption that all providers use the same terms. This checklist supplies no rate or fee estimate; request the current private-pay quote for the trip you are discussing.

A general inquiry does not need a detailed medical history. Ask what information is necessary and how it should be shared before sending sensitive documents. Keep your own notes private.

## Finish by checking what is confirmed

Before the conversation ends, repeat the agreed date, pickup details, destination, travel arrangement and price. Ask whether the reservation is confirmed or whether anything still needs to happen.

Keep the provider's contact details with your trip notes so you can report a change through the agreed channel. For recurring appointments, ask about each proposed arrangement rather than assuming one accepted trip establishes an ongoing reservation.
